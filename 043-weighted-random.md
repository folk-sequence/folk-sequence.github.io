The Steps modulator in Bitwig is not a sequencer. It is a random number generator with memory. Eight slots, each holding a value between zero and one, cycled through in order or shuffled or walked or jumped. The randomness is the point. The memory is the constraint.

This episode ties Steps to Note Transpose, which is tied to Global Key. The chain enforces a scale without enforcing a progression. The modulator suggests. The key says yes or no. Everything that passes through is valid, but not everything is equally likely.

The weights are the composition. Root position gets the most slots in the Steps modulator. The fourth and fifth get fewer. The sixth gets one. The first and second inversion get the leftovers. Roll the dice and the progression moves. But it moves like a folk progression moves — grounded, circular, returning to the root more often than not because that is what the ear expects from this lineage.

The second layer of randomness is the bar count. Not every chord gets one bar. Some get two. Some get half. A second Steps modulator, different rate, different pattern, controlling how long each chord is held before the next one fires. The progression breathes. It does not march.

This is folk livecoding. Not typing code into a terminal while the audience watches. The code is the modulation routing. The terminal is the Bitwig device chain. The livecoding is the decision to reroute, to change a weight, to add a layer, to mute a voice, all while the track is rolling and the clock is counting and there is no undo.

The conventional wisdom says livecoding requires a text editor and a compiler and a community that speaks the same language. The assumption is wrong. Livecoding is any practice where the structure of the music is composed in real time by someone who can see the structure and change it. Bitwig's modulation system is a visual programming language. The wires are the syntax. The devices are the functions. The output is the program running.

What makes this folk is the weighting. A jazz progression weights the extensions — the seventh, the ninth, the thirteenth — and the root is almost an afterthought. A folk progression weights the root and the fourth and the fifth because the song is built for singing around a fire, not for impressing other musicians with harmonic sophistication. The Steps modulator does not know the difference. The producer sets the weights. The tradition is encoded in the slot values.

The machine plays itself, but the machine was told what to favor. That is the whole argument.
